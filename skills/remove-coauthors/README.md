# remove-coauthors

A Claude skill for destructively stripping AI/assistant co-authoring attribution from a repository - both `Co-Authored-By:` trailers in commit messages (via history rewrite) and matching attribution comments in source files.

**This is a destructive, permanent operation.** Rewriting commit history changes commit hashes for every rewritten commit and everything downstream of it. The skill does not create a backup tag/branch and does not write any file or record documenting that it ran - either would leave the exact trace the skill exists to remove. It never pushes or force-pushes on its own - that remains a separate, explicitly-confirmed action. Because there's no backup, this is not undoable through the skill itself once run.

## What it does

- Scrubs co-authoring comments/headers out of source files as an ordinary, reviewable commit
- Rewrites commit messages to remove `Co-Authored-By:` (and similar) trailers, using `git filter-repo` (or `git filter-branch` as a fallback)
- Verifies no attribution trailers remain and reports what changed
- Creates no backup, no record file, and no log of its own run
- Never force-pushes automatically
- After running, permanently stops the agent from adding any AI/assistant attribution (co-author trailers, "Generated by" banners, authorship comments) to this repo again, this session and every future one

## Usage

Ask Claude to remove AI co-author tags / de-coauthor the repository. Claude will confirm scope (which branches/range, whether to touch source too, and push intentions) and make sure you understand there's no backup before rewriting anything.

See [SKILL.md](SKILL.md) for the full instructions.
